# Manual Review Checklist — R06 Connected Experience Prototype (Glass Atlas)

Use this checklist for hands-on UX acceptance review (Aaron Waid) and independent verification (Gamma Review). Launch [`index.html`](./index.html) directly or via local HTTP and use the top **Reviewer Workbench** bar to select and reset scenarios.

## A. Global Navigation & Layout
- [ ] Bottom navigation on phone (`320px` & `375px`) displays exact tabs in order: **`Today | Library | Collections | More`** (no `Archive`, no `My Journey`).
- [ ] Tablet landscape / desktop (`>= 840px`) adapts to a persistent left navigation rail with the main reading column centered vertically (no two-column dashboard).
- [ ] Switching tabs preserves each destination's nested route and scroll position; re-tapping the currently active tab returns to its landing screen at top scroll.
- [ ] Opening any Challenge hides global navigation completely; `Exit` and `Finish` restore the correct originating context.

## B. Eight G09 End-to-End Journeys
- [ ] **1. Normal First Use (`g09-1-normal-first-use`):** Complete or skip 3-screen App Introduction → step through or skip 4-destination Guided App Tutorial (confirm 0 Cards earned) → open Today's Challenge → advance to Screen 2 → `Exit` → verify Today offers `Resume Today's Reading` at Screen 2 → tap `Start from Beginning` → advance to Screen 3 → tap explicit `Finish` → verify Today shows `Completed` + `Read Again`.
- [ ] **2. External First Use (`g09-2-external-first-use`):** Confirm historical `Oct 14` Challenge opens directly *before* App Intro/Tutorial/Monthly Intro → tap `Exit` or `Finish` → verify return goes to **`Today`** (not October Month Screen) without an exit onboarding wall, and Workbench shows `Intro=pending`, `Tutorial=pending`. Open Workbench Controls → test `Embargoed`, `Withdrawn`, and `Invalid` links → confirm neutral fallback + `Return to Today` with zero date/content leakage.
- [ ] **3. Current Month & Preview (`g09-3-current-month`):** Open Today's Challenge directly → confirm NO Monthly Intro interrupts it. Then tap `Current Month` on Today → confirm one-time Monthly Introduction ending in *"Welcome to Paths of Quiet Faith (Synthetic)"*. Verify all 6 Mon–Sun weekly agenda panels scroll continuously, future titles are visible but non-interactive, unearned discoveries show title + numeric progress only (no card art/qualifying list), and Full-Month Card is listed last. Switch to `edge-preview-nov28` and `edge-preview-feb27` → confirm advance preview withholds Welcome, manuscripts, and Monthly Discoveries; then switch date to Dec 1 and verify `Skip to Welcome` appears if previewed.
- [ ] **4. Historical Continuity & Rollover (`g09-4-historical-continuity`):** Verify single `Continue Your Study` card below Today's primary teaching opens unfinished `Oct 3` at Screen 2. In `Library`, set completed `September 2026` as Active Focus → return to `Today` → confirm `Review This Month` (`G01`). Load `edge-rollover-g02` → confirm one-time prior-month continuation disappears after use/leaving Today (`G02`). Load `edge-rollover-g03` → trigger `Simulate Dec 1 Rollover` → confirm `Active Focus` (Oct) and `Kept` (Sep) are protected while oldest unprotected non-focus (Aug) is replaced by Nov (`G03`).
- [ ] **5. Library & Shelf (`g09-5-library-shelf` & `edge-empty-guest`):** Verify welcoming empty Shelf (`0 of 3`, no behind/missed wording). On full 3-slot Shelf, verify Active Focus is ordered first, `Keep on Shelf` → `Kept on Shelf` is distinct from `Active Focus`, `Put Away` on Active Focus opens explicit reassign-or-no-focus modal. Open `Browse All Months` → expand/collapse years, search `Psalms` for unified newest-first results, tap `Load More`, and attempt adding a 4th month (`July 2026`) → verify 2-step replacement chooser + confirmation (`Cancel` changes nothing). Open `Foundations` → verify overview-first + `Resume Reading` + unavailable-reading modal fallback.
- [ ] **6. Earned Collections & Saved Scripture (`g09-6-earned-collections` & `edge-empty-guest`):** On `edge-empty-guest`, verify `Collections` & `Field Notebook` show calm empty states with NO gray silhouettes and NO `Foundations & Learning` or `Special Experiences` entries. On `g09-6-earned-collections`, save a Scripture passage and `Finish` Today (`Nov 18`) → verify combined Today inline announcement → open `View Discoveries` → open newly earned `Everyday Hospitality` full single-scroll Card → test `Share Scripture Card` export preview (confirm Share is NOT present on gallery thumbnails). In `Saved Scripture`, verify Recent / Bible Book / Search / Remove.
- [ ] **7. More, News, Appearance & Replay (`g09-7-news-preferences`):** Open featured update directly → `Back` to `More`. Open `View All News` → test category filters, plus Workbench `News: loading / empty / error` + `Retry`. In `Appearance & Settings`, select `Choose My Colors` (`Cedar & Clay`) + `Dark` contrast → trigger date rollover and verify manual palette persists. Replay `Review Introduction` and `App Tutorial` from `More` → verify both return to `More` with zero data loss and zero Cards awarded.
- [ ] **8. Accounts & Merge (`g09-8-accounts-merge`):** Verify guest `Today` invitation appears after 3 distinct completions → tap `Continue as Guest` → reload browser and verify permanent suppression while `More → Account & Progress` stays accessible. Open simulated Account Merge → run `Partial merge failure` → confirm NO false success claim and local records preserved → tap `Retry Sync Safely` → confirm ONE brief `G08` confirmation on `Today` with the existing-account Shelf precedence sentence.

## C. Accessibility, Reflow & Visual Quality
- [ ] Inspect at `320px`, `375px`, `768×1024`, and `1024×768`: zero horizontal scroll/clipping, readable wrapping of long Challenge titles, >= 44px touch targets.
- [ ] Enable `Text 150%` (or browser 200% zoom) and `Reduced Motion`: layout reflows cleanly without overlap or animation distraction.
- [ ] Navigate with `Tab` / `Shift+Tab` / `Enter` / `Escape`: visible focus rings on all interactive controls, skip-to-content link works, modals & tutorial close cleanly with `Escape` and restore focus.
- [ ] Confirm seasonal/manual palette changes NEVER recolor source Scripture Card SVG illustrations.
